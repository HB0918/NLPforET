# NLPforET
# Vocabulary with Glossing

A web-based vocabulary learning application designed for middle school EFL learners.

## Purpose

This project explores how different glossing conditions influence:

- Vocabulary learning
- Learning efficiency
- Long-term retention

The app compares a traditional gloss condition with a Dynamic Glossing condition inspired by previous vocabulary-learning research.

## Target Vocabulary

- discipline
- reassess
- "me" time
- gathering
- pop up

## Learning Conditions

### Group A
**Korean Gloss Only**

Passage → Korean Meaning → Quiz

### Group B
**Dynamic Glossing**

Additional Context → English Definition → Synonym → Korean Meaning → Quiz

## Assessment

The application provides:

- Immediate vocabulary test
- Delayed vocabulary test
- Automatic score calculation
- Study time tracking
- Learning efficiency calculation

### Learning Efficiency

```
Efficiency = Score ÷ Study Time
```

## Admin Dashboard

The dashboard automatically summarizes:

- Number of participants
- Average score
- Average study time
- Average efficiency
- Average delayed-test score
